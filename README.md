# Skills

Quick use.

```bash
npx skills@latest add AkaCoder404/skills --skill my-skill                   # project-local
npx skills@latest add AkaCoder404/skills --skill my-skill -a claude-code -g      # global for claude
npx skills@latest add AkaCoder404/skills --skill my-skill --global          # ~/.claude/skills/
npx skills@latest add AkaCoder404/skills --list                             # list available skills
```
